# Zakflow — Product Requirements Document

> **Emotional Hook**: A Malaysian worker in Dubai couldn't send Zakat-compliant remittances because no crypto app understands Islamic finance.

## Problem Statement
1.8B Muslims need Shariah-compliant financial tools. Gold-backed PUSD is natural fit but nobody built the remittance layer.

## Solution Overview
Zakat-enabled remittance: send PUSD with auto 2.5% Zakat calculation, gold price display, compliance certificate.

## Core Features (MVP)
1. PUSD remittance send flow
2. Automatic 2.5% Zakat calculation
3. Real-time gold price display
4. Shariah compliance certificate
5. Remittance receipt with gold backing proof

## Success Metrics
- All SDK features demonstrably integrated
- Demo flow works end-to-end

## Out of Scope
- ❌ Actual Shariah certification
- ❌ Fiat on/off ramp
- ❌ Multi-currency
