## Mission
Develop innovative applications that integrate **PUSD** (the non-freezable, USD-pegged stablecoin) as a core component on Solana. PUSD has no freeze function, no blacklist, no pause — compliance enforced at the permissioned mint/redeem layer only.

## Track Scope & Focus Areas
- **Payments & Commerce** — merchant payments, POS, e-commerce
- **DeFi & Yield** — lending, liquidity, yield generation with PUSD
- **Treasury Management** — institutional tooling for PUSD reserves
- **Developer Infrastructure** — SDKs, APIs, tools for PUSD integration
- **Social Impact** — charity, remittances, financial inclusion

## SDK / Integration Primitives
- PUSD SPL token on Solana (standard SPL token interface)
- No freeze/blacklist = censorship-resistant stablecoin
- Permissioned mint/redeem layer only
- Standard Solana wallet + token program integration
